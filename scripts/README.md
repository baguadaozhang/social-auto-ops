# scripts/ — 手工维护脚本（危险，先读再用）

这里的脚本是**一次性手工工具**，用于清理测试期间发出的内容。

**警告**：

- 它们直连 CDP 操作真实账号，**绕过全部风控、配额、拟真层**（固定 sleep、无冷却、无熔断）。
- 只在你明确知道要删哪条内容时手动运行，**不要**被 daemon、计划任务或任何自动化调用。
- 运行前确认 Chrome 已在调试端口 9222 上运行且已登录领英。

| 脚本 | 用途 |
|---|---|
| `delete_post.py` | 删除测试期间发出的帖子 |
| `delete_comment.py` | 删除测试期间发出的评论 |
